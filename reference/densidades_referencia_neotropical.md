# Base de Datos de Referencia Neotropical para Densidad Básica de la Madera (g/cm³)

Base de Datos de Referencia Neotropical para Densidad Básica de la
Madera (g/cm³)

## Usage

``` r
densidades_referencia_neotropical
```

## Value

Vector numérico nombrado con valores de densidad básica de la madera
(g/cm3).

## Examples

``` r
head(densidades_referencia_neotropical)
#>       Cedrela odorata Swietenia macrophylla       Ceiba pentandra 
#>                  0.45                  0.53                  0.25 
#>       Guarea guidonia           Inga edulis    Dipteryx micrantha 
#>                  0.58                  0.55                  0.88 
```
